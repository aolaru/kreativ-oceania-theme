Repository History
------------------

version 1.0.18 (November 2026)
- scoped header navigation styles to avoid interfering with other WordPress navigation markup
- limited the no-menu fallback to top-level pages so nested page hierarchies cannot expand the fixed header
- guarded empty archive pagination output to keep debug-enabled sites free of PHP deprecations
- added a responsive featured-image hero and improved single-post metadata and comment-form presentation
- restored unclipped desktop submenu flyouts and condensed related posts into a compact reading list

version 1.0.17 (November 2026)
- added a dedicated archive template, correct posts-page headings, and archive pagination
- replaced branded thumbnail fallbacks with neutral fixed-ratio media placeholders
- removed the unused legacy logo fallback image
- corrected the main landmark structure and added accessible multi-level mobile menus
- removed legacy marketplace helpers, duplicate template code, and duplicate editor stylesheet loading
- improved dark-mode startup behavior and toggle accessibility

version 1.0.16 (November 2026)
- removed repository-control files that are not accepted in WordPress.org theme packages

version 1.0.15 (November 2026)
- updated the public metadata to use Kreativ WP as the author and the dedicated Kreativ Core page as the theme URL

version 1.0.14 (November 2026)
- fixed mobile menu keyboard focus order and opened-menu focus behavior
- restored standard page loops, editor content, and comments support in the remaining legacy page templates
- corrected page search-result metadata and removed duplicate dark-mode toggle CSS

version 1.0.13 (November 2026)
- added six native Gutenberg patterns in the Kreativ pattern category
- added Journal, Studio, and Portfolio design variations in the Customizer

version 1.0.12 (November 2026)
- removed the legacy framework stylesheet and replaced it with theme-owned responsive layout primitives
- added matching block-editor styles, editor color palette support, and dynamic accent-color styling
- improved default color contrast and consolidated taxonomy archive queries

version 1.0.11 (November 2026)
- unified public templates around the editorial archive layout
- added archive heading, introduction, accent color, and spacing options in the Customizer
- documented release checks for PHP, JavaScript, line endings, and Git whitespace

version 1.0.10 (November 2026)
- fixed stylesheet loading and made the dark-mode toggle reliable when browser storage is unavailable
- added accessible mobile navigation behavior with keyboard escape support
- corrected search result states and pagination, restored standard content loops, and removed the unsafe attachment redirect template
- improved translation coverage, output escaping, and theme resource cleanup for WordPress.org review

version 1.0.9 (October 2026)
- added standards-based navigation, feed, post-class, comments, and threaded-reply support
- added block editor supports, a callout pattern, and configurable header and background settings
- passed Theme Check and WordPress Theme Test Data validation

version 1.0.8 (May 2026)
- removed SEO, social metadata, schema, login customization, and core hook removals from the theme package
- replaced the minified-only distributed stylesheet with a readable compiled stylesheet
- removed ICO assets and aligned theme tags with the WordPress.org allowed tag list

version 1.0.7 (March 2026)
- removed an outdated script enqueue that referenced a deleted source asset
- tightened the public theme metadata for distribution
- prepared a cleaner submission package and release zip

version 1.0.6 (March 2026)
- prepared the theme package for WordPress.org submission
- removed marketplace and plugin-specific templates and helper files
- removed bundled proprietary webfonts and switched the theme to a system font stack
- aligned the text domain and added a generated translation template in /languages
- updated style.css headers and converted readme.txt to WordPress.org format
- normalized line endings across the theme and added .gitattributes

version 1.0.5 (March 2026)
- generalized theme branding and homepage sections for broader reuse
- improved accessibility with skip links, focus states, and better search/menu labeling
- improved responsive image performance using native WordPress image markup
- refreshed the repository documentation with a stronger GitHub README

version 1.0.4 (March 2026)
- renamed the public theme to Kreativ Core and bumped the public version
- updated footer presentation and simplified the screenshot artwork
- refreshed the K logo across favicon, app icons, manifest, and social image assets
- cleaned legacy templates, production links, and unused assets
